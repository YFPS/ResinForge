# BPS 前端拆解：布局、视觉、功能与细节

> 对象：本机安装的 HeyGears Blueprint Studio（`F:\Program Files (x86)\Blueprint Studio`，安装文件日期 2026-04-15；启动时提示最新为 v3.4.0）。
> 方法：带 `--remote-debugging-port` 启动，经 CDP 只读截图、读取计算样式与设计变量（`.ref/bps/cdp.mjs`、`.ref/bps/measure.js`），窗口 1920×1032。截图在本地 `.ref/bps/shots/`（含客户件与设备名，不进仓库），本文用文字与线框描述。
> 技术栈：Electron + Vue 3 + **Naive UI**（`n-button` / `n-flex` / `n-image`…）+ **Tailwind**（`text-xs`、`w-[72px]`、`rounded-lg`）；主题变量 `--color-ufv2-*`。
> 数据结构与文件格式层面的拆解见 [bps-design-analysis.md](./bps-design-analysis.md)。

---

## 1. 一句话

BPS 看起来「专业」靠的不是装饰，而是**克制**：一条黑色窗口栏 + 冷灰阶底色 + 唯一的蓝色主色，**8px 小圆角**，**真实产品照片**表达硬件与材料，界面上处处是**数字和单位**（尺寸、层数、体积、树脂克数、项目占用空间），每个模式都有一句话的说明气泡。它的问题在流程上：两套文件库、零件库是挡住视口的模态框、新建要走五级长页、工程卡片只有时间戳名字。

## 2. 视觉体系（实测）

### 2.1 颜色

| 用途 | 变量 | 值 |
|---|---|---|
| 页面底 | `basic-050` / `basic-100` | `#f8f8f8` / `#eff0f6` |
| 视口底、卡片缩略图底 | `basic-150` | `#e1e5ea` |
| 分隔线、边框 | `basic-200` / `basic-300` | `#d3d6dc` / `#b8bdc6` |
| 次要文字 | `basic-600` / `basic-700` | `#6e7481` / `#585c66` |
| 正文 | `basic-900` | `#29292b` |
| 窗口栏 | `basic-1000` / 黑 | `#121317` / `#000` |
| 主色（导入、应用、选中、层滑块） | `primary-600` / 按下 `primary-700` / 浅底 `primary-100` | `#3760ea` / `#2b4abd` / `#ebf0ff` |
| 次主按钮（新建、使用上一次配置） | 实底深灰 | `#29292b` |
| 状态 | success / warn / error / info | `#27af1a` / `#e87400` / `#d0302f` / `#00a2e8` |
| 场景里 | 支撑橙、选中蓝 + 青色包围框、平台灰格 + 蓝边 | — |

灰阶偏冷（带一点蓝），整套只有一个强调色；橙色只出现在 3D 里的支撑上，不进 UI 控件。

### 2.2 字体与字号

- 系统字体栈（Windows 上是 Segoe UI / 微软雅黑），没有品牌字体。
- 字号阶梯很短：12（标签、卡片名、图标栏文字）/ 14（计数、辅助）/ 15（按钮）/ 18 中粗（栏标题）/ 20 常规（页面标题）。
- 字重只有 400 / 500。页面标题反而用 400，靠字号区分层级。

### 2.3 形状与尺寸

| 元素 | 实测 |
|---|---|
| 窗口栏 | 高 40，纯黑；工作区里显示工程名 |
| 一级图标栏 | 宽 80；条目 72×64，圆角 8；选中 = 白底 + 主色图标与文字（12px） |
| 二级文件夹栏 | 宽 256；上半文件夹树，下半「星标」，中间一条 `#d3d6dc` 分隔线 |
| 主区 | 四周 24 内边距 |
| 大按钮 | 高 40、圆角 8、15px、左右 18；主色蓝 / 次主深灰两种实底 |
| 工程卡片 | 固定宽 240；缩略图 236×166、圆角 8、底 `#e1e5ea`；名称 12px、时间 11px |
| 模态框（零件库） | 960×570、圆角 12 |
| 工作区左栏 | 宽 240，白底 |
| 工作区参数卡 | 约 264 宽，白底圆角，标签在上、控件在下，主操作在卡底 |

**没有药丸形大按钮、没有大圆角卡片、没有渐变和插画**；圆角统一 8（模态 12），阴影很轻。

### 2.4 图像

- 机器：官方产品照片（182×182 白底卡）。
- 附加模块、应用：照片（应用用场景照：通用件、拼装机甲、球形关节人偶、微缩模型）。
- 材料：树脂瓶 + 打样件照片；名称下一行是**用途分类**（标准模型树脂、类 ABS、类 PVC 软质、耐高温模具、水洗原型、防静电…）；多色树脂底部带色点。
- 层厚：三张立体「层叠」图标，标 30 / 50 / 100。
- 工程与零件缩略图：真实 3D 渲染（平台网格 + 灰色模型 + 橙色支撑）。

## 3. 布局（逐屏）

### 3.1 首页三栏（工程 / 切片文件 / 设备）

```text
┌──────────────────────────────────────────────────────────────────────┐ 40 黑色窗口栏：logo …… 反馈 / 通知(10+) / 更多 / 窗口按钮
├─────┬──────────────┬───────────────────────────────────────────────────┤
│头像  │ 切片器        │ ≡ 切片器（面包屑）      [搜索 输入][📁+][导入][＋新建▾] │
│      │ ▸ 文件夹树     │ 切片器                 325 个文件 · 排序 时间↕ · 筛选 › │
│切片器 │              │ ┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐              │
│切片文件│ ──────────── │ │Re  ││RS  ││    ││    ││    ││    │ 6 列 240 宽卡片 │
│设备   │ ★ 星标        │ │图  ││图  ││    ││    ││    ││    │ 悬停：左上复选框 │
│      │              │ └────┘└────┘└────┘└────┘└────┘└────┘ 右上 3D/星标/⋮ │
│ ?    │              │ P_20260918_074051                                  │
│ ⎚    │              │ 2026-09-18 16:42:58                                │
└─────┴──────────────┴───────────────────────────────────────────────────┘
  80        256                    主区（24 内边距）
```

- 「新建」是下拉：本地项目 / 云端项目。
- 多选后工具条出现「移动至」「删除」。
- 卡片左上是机型缩写角标（Re / RS），多版面工程再带一个版面数角标。
- 切片文件页同构：文件夹卡（大黄色文件夹 + 「2 个文件」）、切片卡（名称 + 材料名），悬停多一个「发送到设备」。
- 设备页：下划线页签（打印机 / 其他设备）→ 状态筛选胶囊（空闲 1 / 任务中 / 维护中 / 故障 / 离线 2）+ 机型下拉 → 左侧设备卡（产品照、状态角标、系列名、设备名、所装模块）+ 右侧大详情面板（空态「请选择设备」）。

### 3.2 新建工程配置（整页，不是弹窗）

```text
┌────────────────────────────────────────────────────────┬──────────────┐
│ [使用上一次配置]  ⓘ 请根据打印任务，选择合适的配置……       │ 项目配置   ✕ │
│ 请选择设备型号                                           │ 设备型号      │
│ [照片✓][照片][照片][照片]   ← 选中：蓝描边 + 右上蓝色三角勾 │ [Reflex…]    │
│        └ 悬停弹出规格：成型原理 / 尺寸 / 精度 / 像素 / 波长  │ 附加模块 [无] │
│ 请选择附加模块  [无✓][脉冲剥离模块]                        │ 应用  [通用]  │
│ 请选择应用      [通用][拼装机甲][球形关节人偶][微缩模型]      │ 材料  [ ]    │
│ 请选择材料      20 款瓶装照片墙（名称 + 用途分类）           │ 层厚  [ ]    │
│ 请选择层厚      [30 精细][50 标准][100 快速]               │      [应用]  │
└────────────────────────────────────────────────────────┴──────────────┘
```

- 五级**纵向逐级展开**：选完上一级，下一级出现在下方，页面越拉越长。
- 右侧摘要栏实时回填，五项齐了「应用」才可点。
- 「使用上一次配置」一键回填；橙色提醒条说明配置选错会导致切片不兼容。

### 3.3 工作区

```text
┌──────────────────────────────────────────────────────────────────────┐ 40 窗口栏：logo ⌂ 工程名 ……
├──────────────────────────────────────────────────────────────────────┤ 48 工具条：[▦▾][⇲][⬡]  编辑 支撑 排版 切片  ↶ ↷ 💾 ☁
├────────────┬─────────────────────────────────────────────────────────┤
│模型列表 (2) │ [修复][适印性][一键切片]                    [显示模式组][视角] │
│▾ 版面 01    │ ┌──────────┐                                    ┌────┐  │
│  ⬡ 零件 A …│ │ 模式工具  │        3D 视口（浅灰）                 │视方块│  │
│  ⬡ 零件 B   │ │ 或参数卡  │     平台网格 + 「版面 01」 + 平台工具   └────┘  │
│▾ 出界       │ │ 主操作在底 │                                      ┃ 层  │
│            │ └──────────┘                                      ┃ 滑块 │
│已用项目空间  │                         设备 / 模块 / 材料 / 应用 · 层数 体积 树脂 │
└────────────┴─────────────────────────────────────────────────────────┘
     240
```

- 四个模式页签（编辑 / 支撑 / 排版 / 切片），激活态是梯形「页签」底 + 主色字；每个页签悬停有一句深色说明（如「对选中的模型进行移动、旋转、缩放、复制、打标签、打孔、镂空等等」）。
- 每个模式在视口左侧竖排一列工具（白色方形图标 + 文字）：
  - 编辑：定向、贴底、选择面、移动、旋转、缩放 ‖ 镂空、拆件、打孔、打标、复制、简化
  - 支撑：自动支撑、手动支撑、连杆、删除全部支撑
  - 排版：自动排版
  - 切片：直接是参数卡（切片版面、名称、层厚、Z 补、轮廓补偿、抗锯齿、图像模糊、倒杯口检测、底板层厚自适应、底板高度、同步到云 → 「切片」）
- 左栏是「模型列表」树：版面 → 零件；越界的零件单独归到「出界」；行悬停出「…」：删除 / 取消组合 / **添加至零件库**；底部「已用项目空间」。
- 文件操作收在左上「▦▾」深色下拉：保存项目 / 项目另存为… / 导出所选模型为…
- 右下角常驻工艺与用量信息；选中零件时换成该零件的面数、文件大小、尺寸、体积。
- **零件库是工具条立方体图标打开的模态框**（960×570）：面包屑 + 新建文件夹 + 排序；系统「预设零件」文件夹带锁；零件缩略图里能看到支撑——零件库存的是带支撑的零件（与代码里 `exportToPartLibrary` 把 `supports.bpsc` 打进 `.bpsx` 一致）。

## 4. 交互细节

| 细节 | BPS 的做法 |
|---|---|
| 选中态 | 卡片：2px 蓝描边 + 右上蓝色直角三角 + 白勾；列表：浅灰底 |
| 悬停 | 卡片出复选框与操作簇；树行出「…」；模式页签出说明气泡 |
| 菜单 | 深色底（与浅色界面形成对比），条目白字，不可用项灰字 |
| 提醒 | 页内橙色描边提醒条；弹窗分「提醒 / 确认」两级 |
| 计数 | 处处有数字：325 个文件、空闲 (1)、模型列表 (2)、总层数 2134、树脂 10.56 g |
| 空态 | 图标 + 一句话（「请选择设备」） |
| 文案 | 动词短语，几乎不用形容词；一句话说清功能 |

## 5. 功能设计要点

1. **工程是一等对象**：本地 / 云端两种；文件夹、星标、排序、筛选、导入、批量移动删除；卡片带机型角标与版面数。
2. **切片文件单独成库**：切片产物与工程分开管理，可直接发送到设备。
3. **设备管理**：在线状态、筛选、详情，与工程配置里的「设备型号」是两回事（型号是参数档案，设备是在线实例）。
4. **工艺是五级级联**：设备型号 → 附加模块 → 应用 → 材料 → 层厚，展开成一套参数；支持「使用上一次配置」。
5. **工作区按模式组织**：编辑 / 支撑 / 排版 / 切片，每个模式一列工具 + 参数卡；**一个工程可以有多个版面**，按版面切片。
6. **零件库存带支撑的零件**：从模型行菜单「添加至零件库」，在模态框里按文件夹管理，系统预设零件只读。
7. **用量与空间透明**：层数、体积、树脂克数、工程占用空间常驻。

## 6. 哪些值得学、哪些不照搬

| 值得学（视觉与细节） | 我们的做法 |
|---|---|
| 小圆角（8 / 12）、单一主色、冷灰阶 | Demo 增加「专业紧凑」外观：控件 8、面板 12，去掉大面积药丸与毛玻璃 |
| 处处有数字和单位 | 工程卡、对象行、机器 / 材料选择都带尺寸、点数、层厚、是否放得下 |
| 每个功能一句话说明 | 工具提示与面板说明用动词短语 |
| 带支撑的零件库 | 「加入零件库」时让用户选「连同支撑」，放进工程时支撑跟着走 |
| 「使用上一次配置」 | 新建默认带出上次的机器 / 材料 / 层厚 / 模板 |

| 不照搬（BPS 的短板） | 我们的做法 |
|---|---|
| 零件库是模态框，挡住视口 | 零件库常驻在工作区里（左卡页签 / 抽屉 / 底部胶片条），可直接拖进视口 |
| 新建五级长页，越选越长 | 一屏选完机器 / 材料 / 层厚 / 模板，其余进高级 |
| 工程卡只有时间戳名字和日期 | 卡片带机器、材料、层厚、支撑点数，名字默认取零件名 |
| 换机器看不出零件放不放得下 | 机器列表按同一比例画板面并叠上当前零件占地，直接标「超出 N mm」 |
| 产品照片（版权在厂商） | 用自绘的按比例板面图、树脂色块表达机器与材料，不借用厂商图片 |
| 工程 / 切片文件两套库 | 先只有工程；切片结果作为工程的产物挂在工程下面 |
| 窗口栏 + 工具条两条横带占 88px | 工作区沿用 Studio 的浮动卡片，3D 视口全屏 |

## 7. 对本项目视觉的直接建议

1. **圆角收紧**：Arc 现在是控件 18、面板 26、大量全圆药丸，偏消费类应用；工程工具建议控件 8、面板 12、模态 14，只有开关、标签胶囊保留全圆。Demo 里已做成可切换的「专业紧凑」外观，便于对比。
2. **浮层更实**：毛玻璃（`blur 16px` + 78% 透明）在复杂 3D 场景上会让文字发虚；专业外观改为 92% 实底 + 细边框。
3. **信息密度**：列表行 52～58px、卡片名 13px、辅助 12px、数字等宽；少用大标题。
4. **颜色**：保持单一强调色；支撑色只在 3D 里出现；状态色只用于状态。
